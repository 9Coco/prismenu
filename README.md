# arcMenuOnKde

**Arc Menu for KDE Plasma** — a Plasma 6 application-menu plasmoid with 14 switchable layouts and full graphical configuration, targeting Kubuntu.

See [`plasma-arcmenu/README.md`](plasma-arcmenu/README.md) for install, configuration, and development details.

```bash
cd plasma-arcmenu
./install.sh
python3 tests/validate_requirements.py
```
