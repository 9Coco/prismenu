# Zest Layout

ArcMenu Zest — **three columns**.

```
┌─ 👤 Coco ────┬─ 📌 固定应用 ──┬─ [右侧内容] ────┐
│ 首页 / 文档… │ ⊞ 所有应用*   │ 安 ─────────── │
│ 软件 / 设置  │ 办公 / 编程…  │ 安全中心 …     │
│ ↩ 🔒 ↻ ⏻    │               │ 帮 / 磁 / …    │
│              │ [搜索 跨越中+右栏……………]        │
└──────────────┴───────────────┴────────────────┘
```

- **Left:** avatar, places + software/settings, session buttons
- **Middle:** pinned / all / categories — **controls the right column**
- **Right:** apps for the middle selection (A–Z when “All Applications”)
- Search spans middle + right only
