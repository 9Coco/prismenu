# Brisk Layout (layout 2)

Solus / ArcMenu Brisk-style menu.

The sidebar/content widgets that used to live here (BriskSidebar,
BriskNavRow, BriskContent) were inlined into the single-file layout and
removed. Entry point loaded by the plasmoid: `../LayoutBrisk.qml`
(left sidebar + right content pane are defined inline).
