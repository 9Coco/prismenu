# Mint Layout

Linux Mint Menu style (ArcMenu Mint reference).

```
┌──────┬─ Search ─────────────────────────┐
│ ⚙    │ 固定应用程序 │ 文件 / Prismenu 设置  │
│ 🛒   │ 所有应用程序 │                     │
│ 📁   │ ─────────── │                     │
│ ↩    │ 分类…       │                     │
│ 🔒   │             │                     │
│ ⏻    │             │                     │
└──────┴─────────────┴─────────────────────┘
```

Distinctive: far-left vertical icon rail (settings / software / files / logout / lock / power).
