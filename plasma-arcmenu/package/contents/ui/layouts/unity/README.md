# Unity Layout

ArcMenu Unity compact menu (not Unity Dash).

```
┌─ Search…              ☰ ─┐
│ 已固定 ───────────────   │
│ [文件] [ArcMenu 设置]    │
│ 快捷方式 ─────────────   │
│ [软件][设置][优化][活动] │
│ 🏠 📄 ⬇ 🛍 📁 │ ↩ 🔒 ⏻ │   ← 居中底栏（略深色条）
└──────────────────────────┘
```

- Top: search + hamburger opens **category side panel** (首页 / 所有应用程序 / 分类)
- Pinned icon grid + Shortcuts grid
- Bottom: darker full-width strip; places + session icons centered as one group
