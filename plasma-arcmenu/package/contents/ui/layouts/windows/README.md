# Windows Layout

ArcMenu Windows / Win10 Start style.

```
┌─ ☰ ──┬─ 常用应用程序 ──────┬─ 已固定 ────┐
│      │  [frequent list]    │ [pinned]    │
│      │  安 ──────────────  │  网格       │
│  📁  │  帮 / 磁 / …        │             │
│  ⚙  │  [搜索…]            │             │
│  ⏻  │                      │             │
└──────┴─────────────────────┴─────────────┘
```

- Left: hamburger opens side menu (shortcuts / places / devices); files / settings / power at bottom
- Center: frequent apps + A–Z sections + search at bottom
- Right: pinned icon grid
- Side menu: Back + shortcuts/places/devices | pinned
