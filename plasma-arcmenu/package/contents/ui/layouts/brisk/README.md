# Brisk Layout (layout 2)

Solus / ArcMenu Brisk-style menu.

| File | Role |
|------|------|
| `BriskSidebar.qml` | Left nav: pinned, all apps, categories, software/settings |
| `BriskNavRow.qml` | Sidebar row widget |
| `BriskContent.qml` | Right pane: pinned / category / search list |

Entry point loaded by the plasmoid: `../LayoutBrisk.qml`
